# Fotos que mejorarían la correspondencia con cada destino

El diseño ya incluye una imagen en cada día de las cinco rutas. En varios días se usan las fotos existentes de paisaje, mercados o alojamientos como imágenes de ambiente; no están geolocalizadas y no se describen como fotografías verificadas del destino. Para sustituirlas por escenas reconocibles, serían útiles:

1. Erg Chebbi / Merzouga — necesaria para que la comparación visual con Erg Chigaga sea específica.
2. Marrakech — medina, zocos o paisaje urbano. Hay fotos de riad y mercado, no una vista urbana inequívoca.
3. Taroudant — murallas o medina, para Atlantic to Sahara.
4. Dades — garganta o valle, para The Imperial Journey.
5. Oasis Fint — paisaje identificable del oasis.
6. Valle del Drâa — palmerales y kasbahs.
7. Casablanca — solo si se mantiene esa ciudad como una de las dos opciones de inicio de The Imperial Journey.
8. Ouirgane — paisaje de montaña/pueblo, si hay una imagen propia.

No hacen falta fotos adicionales para desplegar esta revisión privada; estos archivos permitirían afinar su autenticidad visual.
